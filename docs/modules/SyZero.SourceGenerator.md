# SyZero.SourceGenerator

基于 Roslyn 的 **增量源生成器** 包，目前内置两个 generator：

- **`SyServiceMarkerGenerator`**：扫描所有继承 `IApplicationService` 的类型，生成 `SyZero.SourceGenerator.Generated.SyDiscoveredServices.Names` 字符串数组（可作为后续诊断 / 文档生成的入口）。
- **`SyDIRegistrationGenerator`**：扫描所有实现 `SyZero.Dependency.IScopedDependency` / `ISingletonDependency` / `ITransientDependency` 的非抽象类，生成 `SyZero.SourceGenerator.Generated.SyZeroGeneratedRegistration.AddSyZeroGenerated(IServiceCollection)` 扩展方法 — 编译期完成 DI 注册，**可替代运行时反射扫描**。

## 📦 安装

```bash
dotnet add package SyZero.SourceGenerator
```

> 该包以 **analyzer 形式** 被消费，编译期生效，不会进入运行时依赖。

## 🚀 使用：DI 注册自动生成

业务侧只需正常实现 SyZero 的依赖标记接口：

```csharp
public interface IOrderService { Task PlaceAsync(); }

public class OrderService : IOrderService, IScopedDependency
{
    public Task PlaceAsync() => Task.CompletedTask;
}

public class MetricsCollector : ISingletonDependency { /* ... */ }
public class IdGenerator : ITransientDependency { /* ... */ }
```

编译后 generator 会发出：

```csharp
// <auto-generated />
namespace SyZero.SourceGenerator.Generated
{
    internal static class SyZeroGeneratedRegistration
    {
        public static IServiceCollection AddSyZeroGenerated(this IServiceCollection services)
        {
            services.AddScoped<global::Demo.OrderService>();
            services.AddScoped<global::Demo.IOrderService>(sp => sp.GetRequiredService<global::Demo.OrderService>());
            services.AddSingleton<global::Demo.MetricsCollector>();
            services.AddTransient<global::Demo.IdGenerator>();
            return services;
        }
    }
}
```

`Program.cs` 一行接入：

```csharp
builder.Services.AddSyZeroGenerated();
```

> 同一个实现 + 多个业务接口时，使用 `sp.GetRequiredService<TImpl>()` 复用单实例，避免重复注册造成实例分裂。抽象类、未实现任何 `I*Dependency` 的类型自动跳过。

## 🚀 使用：服务清单生成

```csharp
// <auto-generated />
namespace SyZero.SourceGenerator.Generated
{
    internal static class SyDiscoveredServices
    {
        public static readonly string[] Names = new string[] { "OrderService", "CustomerService" };
    }
}
```

## 🛠 自定义

派生新的 `[Generator] : IIncrementalGenerator`，参考 [SyServiceMarkerGenerator](https://github.com/HaitaoJin/SyZero/blob/main/src/SyZero.Module/SyZero.SourceGenerator/SyServiceMarkerGenerator.cs) 与 [SyDIRegistrationGenerator](https://github.com/HaitaoJin/SyZero/blob/main/src/SyZero.Module/SyZero.SourceGenerator/SyDIRegistrationGenerator.cs)。

## ⚠️ 注意

- 本包目标框架为 `netstandard2.0`（Roslyn analyzer 必须）。
- 在测试项目调试 generator 时，可使用 `CSharpGeneratorDriver.Create(new SyDIRegistrationGenerator()).RunGenerators(compilation)`，再读取 `GetRunResult().GeneratedTrees`。
