# SyZero.ObjectMapping.AutoMapper

SyZero.ObjectMapping.AutoMapper integrates AutoMapper with SyZero and supports automatic profile scanning and dependency injection registration.

## Install

```bash
dotnet add package SyZero.ObjectMapping.AutoMapper
```

## Key Features

- Automatic Profile scanning
- Seamless DI registration
- Type-safe object mapping
- Collection and nested-object mapping support

## Quick Start

```csharp
builder.Services.AddSyZeroAutoMapper();
```
