# SyZero.SourceGenerator

Roslyn **incremental source generator** package. Ships two generators today:

- **`SyServiceMarkerGenerator`** — discovers types implementing `IApplicationService` and emits `SyZero.SourceGenerator.Generated.SyDiscoveredServices.Names`.
- **`SyDIRegistrationGenerator`** — discovers non-abstract classes implementing `SyZero.Dependency.IScopedDependency` / `ISingletonDependency` / `ITransientDependency` and emits `SyZero.SourceGenerator.Generated.SyZeroGeneratedRegistration.AddSyZeroGenerated(IServiceCollection)`. **Compile-time DI** — drop-in replacement for runtime reflection scanning.

## 📦 Install

```bash
dotnet add package SyZero.SourceGenerator
```

> Consumed as an analyzer: applied at build time, no runtime dependency.

## 🚀 Compile-time DI registration

Implement the SyZero dependency markers as usual:

```csharp
public interface IOrderService { Task PlaceAsync(); }

public class OrderService : IOrderService, IScopedDependency
{
    public Task PlaceAsync() => Task.CompletedTask;
}

public class MetricsCollector : ISingletonDependency { /* ... */ }
public class IdGenerator : ITransientDependency { /* ... */ }
```

The generator emits:

```csharp
// <auto-generated />
namespace SyZero.SourceGenerator.Generated
{
    internal static class SyZeroGeneratedRegistration
    {
        public static IServiceCollection AddSyZeroGenerated(this IServiceCollection services)
        {
            services.AddScoped<global::Demo.OrderService>();
            services.AddScoped<global::Demo.IOrderService>(sp => sp.GetRequiredService<global::Demo.OrderService>());
            services.AddSingleton<global::Demo.MetricsCollector>();
            services.AddTransient<global::Demo.IdGenerator>();
            return services;
        }
    }
}
```

Wire it up in `Program.cs`:

```csharp
builder.Services.AddSyZeroGenerated();
```

> When a single implementation also implements one or more business interfaces, the generator routes interfaces through `sp.GetRequiredService<TImpl>()` so they share the same instance per scope. Abstract classes and types without any `I*Dependency` marker are skipped.

## 🛠 Service catalog generator

```csharp
// <auto-generated />
namespace SyZero.SourceGenerator.Generated
{
    internal static class SyDiscoveredServices
    {
        public static readonly string[] Names = new string[] { "OrderService", "CustomerService" };
    }
}
```

Target framework is `netstandard2.0` (required by Roslyn analyzers). Use `CSharpGeneratorDriver.Create(new SyDIRegistrationGenerator()).RunGenerators(compilation)` in tests, then inspect `GetRunResult().GeneratedTrees`.
